# CareConnect

A simple Flutter app with three screens:

1. Doctor list with qualifications and specialties.
2. Patient form with name, age, gender, date of birth, issue, and doctor selection.
3. Appointment confirmation with a date set 3 days after form submission.

## Run

If platform folders are not generated yet, run:

```powershell
flutter create --platforms=android,web,windows .
```

Then run the app:

```powershell
flutter pub get
flutter run
```
